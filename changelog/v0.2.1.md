# Version 0.2.1

**Release Date**: November 13, 2026

## Fixed

- **CNPJ.ws phone normalization** ([#1](https://github.com/dssiqueira/n8n-nodes-cnpj-hub/issues/1)): `contato.telefone` no longer contains the literal string `"undefined"` (e.g. `"11undefined"`) when the API returns only the area code or only the number. A phone without a number is dropped; a number without an area code is kept as-is.
- **Codex metadata** ([#2](https://github.com/dssiqueira/n8n-nodes-cnpj-hub/issues/2)): `CNPJHUB.node.json` now identifies the node with the package name (`n8n-nodes-cnpj-hub`) instead of the reserved `n8n-nodes-base` prefix, as required for community nodes.
- **Build**: the rate-limit delay now uses `sleep` from `n8n-workflow` instead of the global `setTimeout`, which was breaking `tsc` (and therefore `npm publish`).
- **Documentation link** in the codex file pointed to the wrong GitHub user.

## Changed

- When a **Specific API** fails, the node now throws `NodeApiError` instead of `ApplicationError`, preserving the HTTP status code and showing n8n's friendly message (e.g. "too many requests" for 429). The failing API and original error are kept in the error description. The "All APIs failed" error in fallback mode is unchanged.

## Technical Details

### Files Modified

- `nodes/CNPJHUB/Cnpjhub.node.ts`
  - New `buildPhone(ddd, phone)` helper used by the `cnpjws` normalization
  - `NodeApiError` for specific-API failures (passed through the outer catch untouched)
  - `setTimeout` replaced by `sleep` from `n8n-workflow`
- `nodes/CNPJHUB/CNPJHUB.node.json`
  - `node`: `n8n-nodes-base.CNPJHUB` → `n8n-nodes-cnpj-hub`
  - Documentation URL fixed
- `package.json` / `package-lock.json`
  - Version bump: 0.2.0 → 0.2.1

## Breaking Changes

None. The codex `node` field is metadata only; the node type used in workflows (`n8n-nodes-cnpj-hub.cnpjhub`) did not change.

No migration needed.
