# Version 0.2.0

**Release Date**: January 9, 2025

## Added

- **New API Support**: OpenCNPJ integration
  - Free API with monthly updated database
  - Full download option available
  - Complete data normalization support
- OpenCNPJ added to API selection dropdown
- OpenCNPJ added to automatic fallback chain

## Changed

- Updated project description from 5 to 6 supported APIs
- Improved API descriptions in documentation
- BrasilAPI correctly labeled as "Community" project instead of "Official"

## Documentation

- Updated README.md with OpenCNPJ information
- Updated README-pt.md with OpenCNPJ information
- Enhanced API descriptions for clarity
- Fixed contact information formatting

```typescript
case 'opencnpj':
  normalized.cnpj = data.cnpj
  normalized.razao_social = data.razao_social
  normalized.nome_fantasia = data.nome_fantasia
  normalized.situacao = data.situacao_cadastral
  normalized.data_abertura = data.data_inicio_atividade
  normalized.porte = data.porte_empresa
  normalized.natureza_juridica = data.natureza_juridica
  normalized.capital_social = data.capital_social
  normalized.atividade_principal.codigo = data.cnae_principal
  normalized.endereco = { logradouro, numero, complemento, bairro, cep, municipio, uf }
  normalized.contato.telefone = data.telefones (formatted)
  normalized.contato.email = data.email
  normalized.socios = data.QSA (mapped)
  normalized.atividades_secundarias = data.cnaes_secundarios
  normalized.simples.optante = data.opcao_simples
  normalized.simples.data_opcao = data.data_opcao_simples
```
