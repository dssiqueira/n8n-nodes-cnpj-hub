# Version 0.1.0

**Release Date**: August 13, 2025

## Added

- Initial release of n8n-nodes-cnpj-hub
- Support for 5 public Brazilian CNPJ APIs:
  - CNPJ.ws (Most Complete)
  - CNPJA (Structured)
  - MinhaReceita (Detailed)
  - BrasilAPI (Community)
  - ReceitaWS (Simple)
- **Automatic Fallback**: Tries multiple APIs if one fails
- **Rate Limiting**: Configurable delay between requests (0-60000ms)
- **Data Normalization**: Standardized output format across all APIs
- **Smart Validation**: Accepts CNPJ with or without formatting
- **Dual Format Support**: Original or Normalized data output
- **Detailed Metadata**: Information about APIs used and attempts
- **Error Handling**: Robust error management with continue-on-fail support
- Bilingual documentation (English and Portuguese)

## Features

### API Strategy Selection
- **Specific API**: Use only one chosen API
- **Automatic Fallback**: Try APIs in sequence until success

### Data Formats
- **Normalized Mode**: Standardized fields across all APIs
  - Company identification (CNPJ, legal name, trade name)
  - Registration status and opening date
  - Company size and legal nature
  - Share capital
  - Main and secondary business activities (CNAE codes)
  - Complete address information
  - Contact details (phone, email)
  - Partners/shareholders information
  - Tax regime (Simples Nacional) status
- **Original Mode**: Raw API response for maximum flexibility

### Validation & Error Handling
- CNPJ format validation (14 digits required)
- Automatic character stripping (accepts formatted or plain CNPJs)
- Comprehensive error messages
- Continue-on-fail support
- Metadata tracking for debugging

### Rate Limiting
- Configurable delay between requests
- Range: 0 to 60,000 milliseconds
- Helps avoid API blocking
- Expression support for dynamic delays

### API Endpoints

```
CNPJ.ws:      https://publica.cnpj.ws/cnpj/{cnpj}
CNPJA:        https://open.cnpja.com/office/{cnpj}
MinhaReceita: https://minhareceita.org/{cnpj}
BrasilAPI:    https://brasilapi.com.br/api/cnpj/v1/{cnpj}
ReceitaWS:    https://receitaws.com.br/v1/cnpj/{cnpj}
```

### Node Parameters

1. **Operation**: consultarCnpj (Query CNPJ)
2. **API Strategy**: fallback | specific
3. **API**: cnpjws | cnpja | minhareceita | brasilapi | receitaws
4. **Request Delay (Ms)**: 0-60000 (string, supports expressions)
5. **Data Format**: normalized | original
6. **CNPJ**: 14-digit number (required)

### Metadata Structure

```json
{
  "_meta": {
    "api_utilizada": "string",
    "cnpj_consultado": "string",
    "data_consulta": "ISO 8601 timestamp",
    "estrategia": "fallback | specific",
    "data_format": "normalized | original",
    "apis_tentadas": ["array of error messages"],
    "original_data": {} // only in normalized mode
  }
}
```

## Known Limitations

- API availability depends on third-party services
- No authentication/API key support (uses public endpoints)
