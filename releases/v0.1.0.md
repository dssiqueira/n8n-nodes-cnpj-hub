# Release Notes - v0.1.0

**Release Date**: January 8, 2025

## 🎉 Initial Release

Welcome to the first release of **n8n-nodes-cnpj-hub**! This custom node brings powerful Brazilian CNPJ (company registry) data querying capabilities to your n8n workflows.

## ✨ Features

### Multi-API Support

Query CNPJ data from **5 different public APIs**:

1. **CNPJ.ws** - Most comprehensive data with detailed partner information
2. **CNPJA** - Well-structured and organized data format
3. **MinhaReceita** - Detailed information with tax regime data
4. **BrasilAPI** - Community-driven open source project
5. **ReceitaWS** - Simple and fast for basic queries

### Automatic Fallback

Never worry about API downtime! The node automatically tries alternative APIs if one fails:

- Tries APIs in sequence until success
- Tracks which APIs were attempted
- Returns detailed error information
- Configurable to use a specific API if needed

### Data Normalization

Get consistent data format regardless of which API responds:

- **Normalized Mode**: Standardized fields across all APIs
- **Original Mode**: Raw API response for maximum flexibility
- Automatic field mapping and transformation
- Consistent structure for easy workflow integration

### Smart Features

- ✅ **CNPJ Validation**: Accepts formatted (11.222.333/0001-81) or plain (11222333000181) CNPJs
- ⏱️ **Rate Limiting**: Configurable delay (0-60000ms) between requests
- 🛡️ **Error Handling**: Robust error management with continue-on-fail support
- 📝 **Metadata Tracking**: Detailed information about API usage and attempts
- 🌍 **Bilingual Docs**: Complete documentation in English and Portuguese

## 🚀 Getting Started

### Installation

```bash
npm install n8n-nodes-cnpj-hub
```

### Basic Usage

1. Add the **CNPJ HUB** node to your workflow
2. Enter a CNPJ number (with or without formatting)
3. Choose your preferred API strategy:
   - **Automatic Fallback** (recommended): Tries multiple APIs
   - **Specific API**: Use only one API
4. Select data format:
   - **Normalized**: Consistent format across all APIs
   - **Original**: Raw API response
5. Execute!

### Example Workflow

```
Webhook → CNPJ HUB → Process Data → Send Email
```

## 📊 Data Structure

### Normalized Output Includes

- Company identification (CNPJ, legal name, trade name)
- Registration status and opening date
- Company size and legal nature
- Share capital
- Main and secondary business activities (CNAE codes)
- Complete address information
- Contact details (phone, email)
- Partners/shareholders information
- Tax regime (Simples Nacional) status

### Metadata

Every response includes metadata:

- `api_utilizada`: Which API provided the data
- `cnpj_consultado`: The CNPJ that was queried
- `data_consulta`: Query timestamp
- `estrategia`: Strategy used (fallback/specific)
- `data_format`: Format returned (normalized/original)
- `apis_tentadas`: List of failed attempts (fallback mode only)

## 🔧 Configuration Options

### API Strategy

- **Automatic Fallback**: Tries APIs in order until success
- **Specific API**: Use only your chosen API

### Request Delay

- Range: 0 to 60,000 milliseconds
- Helps avoid rate limiting
- Configurable per request

### Data Format

- **Normalized**: Standardized across all APIs
- **Original**: Raw API response
