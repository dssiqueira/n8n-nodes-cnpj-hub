# Release Notes - v0.2.1

**Release Date**: November 13, 2026

A bug-fix release. No changes needed in your workflows.

## 🐛 Bug Fixes

- **No more `"undefined"` in phone numbers**: when CNPJ.ws returned only part of a phone (area code without number, or the reverse), the normalized `contato.telefone` could come out as `"11undefined"`. Fixed ([#1](https://github.com/dssiqueira/n8n-nodes-cnpj-hub/issues/1)).
- **Correct community node metadata**: the codex file no longer uses the `n8n-nodes-base` prefix reserved for official n8n nodes ([#2](https://github.com/dssiqueira/n8n-nodes-cnpj-hub/issues/2)).
- **Build fixed**: the package compiles again with `npm run build`.

## 🔧 Improvements

- **Clearer errors with a specific API**: if the chosen API fails, the error now shows the HTTP status and n8n's standard message (for example, "too many requests" on a 429), plus which API failed.

## 🚀 Upgrade Guide

```bash
npm update n8n-nodes-cnpj-hub
```

Or update it from **Settings → Community Nodes** in n8n, then restart your instance.
