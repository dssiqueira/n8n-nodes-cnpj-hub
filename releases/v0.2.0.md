# Release Notes - v0.2.0

**Release Date**: November 13, 2026

## 🎉 What's New

### New API Integration: OpenCNPJ

We're excited to announce support for a 6th API! **OpenCNPJ** is now available as a data source option.

#### Why OpenCNPJ?

- ✅ **Free and Open**: Completely free API with no rate limits
- 📅 **Monthly Updates**: Database updated monthly with official data
- 💾 **Full Download**: Option to download complete database
- 🔄 **Reliable**: Community-maintained with consistent uptime

### How to Use

OpenCNPJ is automatically included in the fallback chain. You can also select it specifically:

1. Set **API Strategy** to "Specific API"
2. Choose **OpenCNPJ** from the API dropdown
3. Query your CNPJ as usual

### Alphanumeric CNPJ support

Since July 31, 2026 the Receita Federal issues CNPJs with letters (e.g. `12.ABC.345/01DE-35`). The node now accepts them, with or without the mask, in upper or lower case.

### Check-digit validation

Every CNPJ (numeric or alphanumeric) is validated locally before any request. Typos fail instantly with a clear error instead of burning calls on every API.

## ⚡ Performance

- **Smarter delay**: the Request Delay is now the minimum interval between two calls to the *same* API. The first request doesn't wait, and when an API fails in fallback mode the next one is tried right away. A fallback across 3 APIs with a 2s delay went from ~6s to near-instant.
- **No duplicate queries**: if the same CNPJ appears more than once in the input (even with different formatting), it's queried only once per execution.

## 🔧 Improvements

- **Clearer errors with a specific API**: failures show the HTTP status and n8n's standard message (e.g. "too many requests" on a 429), plus which API failed.

### Documentation Updates

- **Accurate API Descriptions**: Each API now has a unique, accurate description
- **BrasilAPI Correction**: Properly labeled as a community project (not official government API)
- **Enhanced Clarity**: Improved descriptions for all APIs

### Technical Changes

- Updated package version to 0.2.0
- Added OpenCNPJ normalization logic
- Expanded API array to include OpenCNPJ endpoint
- Updated all documentation files (README.md, README-pt.md)

## 📊 Supported APIs (6 Total)

1. **CNPJ.ws** - Most comprehensive data
2. **CNPJA** - Well-structured format
3. **MinhaReceita** - Detailed tax information
4. **BrasilAPI** - Community-driven project
5. **OpenCNPJ** - Free with monthly updates ⭐ NEW
6. **ReceitaWS** - Lightweight and fast

## 🚀 Upgrade Guide

### For New Users

Simply install the latest version:

```bash
npm install n8n-nodes-cnpj-hub
```

### For Existing Users

Update to the latest version:

```bash
npm update n8n-nodes-cnpj-hub
```

Then restart your n8n instance.

## 🐛 Bug Fixes

- **No more `"undefined"` in phone numbers** from CNPJ.ws when only part of the phone was returned ([#1](https://github.com/dssiqueira/n8n-nodes-cnpj-hub/issues/1))
- **Correct community node metadata**: the codex file no longer uses the `n8n-nodes-base` prefix reserved for official nodes ([#2](https://github.com/dssiqueira/n8n-nodes-cnpj-hub/issues/2))
- **Build fixed**: the package compiles again with `npm run build`

## ⚠️ Breaking Changes

- None in the output format
- CNPJs with wrong check digits are now rejected up front instead of being sent to the APIs

## 📝 Notes

- OpenCNPJ is automatically added to the fallback chain
