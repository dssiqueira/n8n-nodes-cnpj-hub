# Release Notes - v0.2.0

**Release Date**: January 9, 2025

## 🎉 What's New

### New API Integration: OpenCNPJ

We're excited to announce support for a 6th API! **OpenCNPJ** is now available as a data source option.

#### Why OpenCNPJ?

- ✅ **Free and Open**: Completely free API with no rate limits
- 📅 **Monthly Updates**: Database updated monthly with official data
- 💾 **Full Download**: Option to download complete database
- 🔄 **Reliable**: Community-maintained with consistent uptime

### How to Use

OpenCNPJ is automatically included in the fallback chain. You can also select it specifically:

1. Set **API Strategy** to "Specific API"
2. Choose **OpenCNPJ** from the API dropdown
3. Query your CNPJ as usual

## 🔧 Improvements

### Documentation Updates

- **Accurate API Descriptions**: Each API now has a unique, accurate description

## 📊 Supported APIs (6 Total)

1. **CNPJ.ws** - Most comprehensive data
2. **CNPJA** - Well-structured format
3. **MinhaReceita** - Detailed tax information
4. **BrasilAPI** - Community-driven project
5. **OpenCNPJ** - Free with monthly updates ⭐ NEW
6. **ReceitaWS** - Lightweight and fast

## 🚀 Upgrade Guide

### For New Users

Simply install the latest version:

```bash
npm install n8n-nodes-cnpj-hub
```

### For Existing Users

Update to the latest version:

```bash
npm update n8n-nodes-cnpj-hub
```

Then restart your n8n instance.
